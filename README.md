| File | Purpose |

## 🌐 Make It PUBLIC (GitHub Pages)

### Step 1: Run Setup
1. Double-click **`SETUP_GITHUB.bat`**
2. Enter your GitHub username when prompted
3. Follow the on-screen instructions to create a GitHub repo

### Step 2: Enable GitHub Pages
1. Go to: `https://github.com/YOUR_USERNAME/91-cc-numbers-re/settings/pages`
2. Under **Source**, select **Deploy from a branch**
3. Select branch: `main` (or `master`)
4. Select folder: `/` (root)
5. Click **Save**

### Step 3: Your Public URL
After 2-3 minutes, your dashboard will be live at:
```
https://YOUR_USERNAME.github.io/91-cc-numbers-re/dashboard.html
```

**Anyone with this link can view your dashboard — no login required!**

## 🔄 One-Click Refresh

Every time your Google Sheet is updated, just double-click:

### `REFRESH_AND_PUBLISH.bat`

This will:
1. ✅ Fetch fresh data from your Google Sheet
2. ✅ Rebuild the dashboard HTML
3. ✅ Push to GitHub (updates your public URL automatically)

**That's it — your public dashboard updates in under 1 minute!**

- **Interactive Charts** — Line charts for trends, bar charts for YoY comparison
- **Data Labels** — Actual numbers shown on every chart (no "k" formatting)
